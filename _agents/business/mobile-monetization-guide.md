## 🅱️ 자동화 시스템형 5가지 (1회 구축 → 반복 매출)

각 항목은 **가설 → 검증 지표 → 투입 → 예상 산출 → 자동화 스택 → 리스크** 순으로 정리.

### 1) 디지털 상품 자동 판매 (노션 템플릿·전자책·프롬프트팩)

- **가설(H)**: 특정 직군(예: 1인 기업가, 마케터)에게 1~3만원대 노션 템플릿/프롬프트팩이 월 30~100건 팔린다.
- **검증 지표(V)**: 2주 내 랜딩 → 결제 전환율 ≥ 1.5%, 누적 판매 ≥ 10건, 환불률 ≤ 5%.
- **투입(I)**: 시간 30~60h(첫 상품) / 비용 5~20만원(디자인·마켓 수수료).
- **산출(O)**: 보수 10만 / 평균 50만 / 낙관 300만+ (월).
- **스택(S)**: 크몽·탈잉·Gumroad·Creem / Notion / Canva / Lemon Squeezy.
- **리스크(R)**: 카피 상품 범람 → 차별화 콘셉트·업데이트 정책 필수.

### 2) AI 자동 포스팅 블로그 + 광고

- **H**: 롱테일 키워드(월 1k~10k 검색) 100개 타겟, AI 초안 + 인간 검수로 SEO 누적 트래픽 확보.
- **V**: 8주 내 일 방문자 500+, 클릭당 RPM ₩200+, 색인율 ≥ 70%.
- **I**: 시간 주 5~10h / 비용 월 5~15만원(API + 호스팅 + 도구).
- **O**: 보수 0 / 평균 30만 / 낙관 500만+ (월) — 6개월 누적 가정.
- **S**: 티스토리·워드프레스 / Claude API / 네이버 애드포스트·구글 애드센스 / Make.com·n8n / Search Console.
- **R**: AI 콘텐츠 정책(검색엔진 핵심 업데이트), 저품질 양산 시 색인 제외.

### 3) 유튜브 쇼츠/롱폼 반자동 양산

- **H**: 특정 니치(예: 1인 기업 케이스 스터디)에서 쇼츠 일 1편 + 롱폼 주 1편 양산 시 12주 내 1,000 구독·4,000 시청시간.
- **V**: 4주 내 평균 조회수 ≥ 5,000, 시청 지속률 ≥ 40%, 구독 전환 ≥ 1%.
- **I**: 시간 주 8~12h / 비용 월 10~30만원(TTS·편집·썸네일).
- **O**: 보수 0 / 평균 50만 / 낙관 500만+ (월) — 광고+쇼츠 펀드+제휴 합산.
- **S**: ElevenLabs(TTS) · CapCut/HeyGen · 자동 자막(Whisper) · YouTube Studio 예약 업로드 · TubeBuddy.
- **R**: AI 콘텐츠 표시 정책, 저작권(BGM·푸티지), 정책 위반 시 채널 리스크.

### 4) 스마트스토어 위탁판매 자동화

- **H**: 마진 20~30% 카테고리 50~100개 SKU 자동 등록, 키워드·후기 관리로 월 100~500건 주문.
- **V**: 6주 내 SKU당 주간 노출 ≥ 200, 전환율 ≥ 1.2%, 반품률 ≤ 5%.
- **I**: 시간 주 6~10h / 비용 월 10~30만원(자동화 SaaS + 광고).
- **O**: 보수 30만 / 평균 200만 / 낙관 1,000만+ (월).
- **S**: 사방넷·셀러봇캣 / 도매매·온채널·도매꾹 / CS 챗봇(채널톡) / 네이버 광고.
- **R**: 가격 경쟁·반품 처리·정산 주기. 위탁사 품절·배송 지연 = 페널티 누적.

### 5) 제휴마케팅 + AI 콘텐츠 파이프라인

- **H**: 쿠팡파트너스 + Threads/X/블로그 멀티 채널에 AI 카피 자동 배포 시 EPC ₩200+, 월 클릭 10k+.
- **V**: 4주 내 클릭 ≥ 5,000, 구매 전환율 ≥ 2%, 차단·정책 위반 0건.
- **I**: 시간 주 4~8h / 비용 월 5~10만원(API + 스케줄러).
- **O**: 보수 10만 / 평균 80만 / 낙관 500만+ (월).
- **S**: 쿠팡파트너스·아마존 어소시에이트 / Claude API / Threads·X·블로그 / Buffer·Make·n8n / Google Analytics.
- **R**: 플랫폼별 제휴 링크 정책, 스팸 판정, 단가 변동.
