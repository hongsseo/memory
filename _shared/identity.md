# 🏢 회사 정체성

- **회사 이름:** 세상을 탐닉하다
- **로고 슬로건:** 세상의 모든 지혜는 자연으로부터 온다
- **한 줄 소개:** 세상의 모든 지식을 콘텐츠로 만드는 1인 기업가
- **타깃 청중:** 30·40대 지적 호기심이 가득한 사람들
- **브랜드 톤:** 데이터 기반, 친근하게
- **금기:** 정치 주제, 선정적이고 폭력적인 것
