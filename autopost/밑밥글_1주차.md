# 🧵 오늘살림 스레드 밑밥글 — 1주차 (링크 없음 · 알고리즘 신뢰 빌드업)

> **왜 밑밥글?** 새 계정이 바로 링크를 올리면 스팸봇으로 차단됨.
> 첫 일주일은 **링크·상품·고지문 없이** 순수 공감글만 올려 알고리즘 신뢰도를 쌓는다.
> **페르소나:** 30대 직장인 · 살림/절약을 챙기는 현실적인 사람 (오늘살림 = "계산해주는 살림").
> **원칙:** 첫 줄에 훅(수치·결과·공감) / 3~5줄 이내 / 끝에 가벼운 질문으로 소통 유도.
> **타이밍:** 오전 8시(출근길) · 오후 6시(퇴근길) 하루 2개.
> **주의:** 이 주차엔 절대 링크·상품 언급 X. 8일차부터 상품글 시작(그땐 고지문 상단 필수).

---

## Day 1
**🌅 오전 8시**
```
출근하기도 전에 이미 지친 사람 나만 아니지…?

근데 아침에 딱 하나, 어제 돌린 빨래 널어놓고 나오면
퇴근하고 집 왔을 때 그게 그렇게 든든하더라고요.

여러분은 아침에 뭐 하나 하고 나와요?
```
**🌆 오후 6시**
```
퇴근하고 집 오면 제일 먼저 뭐 해요?

저는 무조건 손 씻고 물 한 컵.
집안일은 그 다음에… 아니 사실 좀 쉬다가 해요 ㅎㅎ

바로 일 시작하는 사람 있어요? 존경합니다 진심.
```

## Day 2
**🌅 오전 8시**
```
월급은 그대로인데 장바구니만 무거워지는 이 느낌…

이번 달은 진짜 냉장고부터 털어보기로 했어요.
장 보러 가기 전에 냉장고 사진 한 장 찍는 것부터.

다들 식비 어떻게 관리해요? 팁 좀 나눠줘요.
```

```
설거지 쌓아두고 '이따 해야지' 했다가
결국 자기 전에 후회하는 거… 저만 그래요?

오늘은 밥 먹자마자 바로 해버렸더니
저녁이 통째로 여유로워졌어요.

미루기파 vs 바로파, 여러분은?
```

## Day 3
**🌅 오전 8시**

```
그 5분이 세상에서 제일 어렵죠…

오늘은 성공해서 커피 한 잔 여유롭게 마시고 나왔어요.
```

```
오늘 퇴근하고 안 쓰는 코드부터 몇 개 뽑아보려고요.

여러분 집에서 제일 먼저 뽑을 건 뭐예요?
```

```
매일 아침 또 백지에서 시작해요 ㅎㅎ
```

```
매주 고민하는데 결국 몰아서 하게 되더라고요.

주말 청소파 계세요?
```

```
여러분의 일요일 밤 루틴은요?
```
