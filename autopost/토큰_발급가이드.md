# 🔑 오늘살림 Meta 토큰 발급 가이드 (IG + Threads)

> 목표: `autopost/config.json`에 넣을 4개 값 확보
> — `ig.accessToken` / `ig.igUserId` / `threads.accessToken` / `threads.threadsUserId`
> ⚠️ 토큰은 비밀번호급. 채팅·깃에 절대 붙여넣지 말 것. 오직 로컬 `config.json`에만.

---

## 0. 준비 (한 번만)
- [ ] 오늘살림 인스타를 **프로페셔널(크리에이터/비즈니스)** 로 전환 → 이미 완료(크리에이터·개인블로그)
- [ ] PC 브라우저에서 오늘살림 인스타/쓰레드에 로그인 상태
- [ ] https://developers.facebook.com 접속 → 우상단 **로그인**(오늘살림과 연결된 페북/메타 계정)

---

## A. 앱 준비 — BlueSeyo 앱 재사용 (권장)
1. developers.facebook.com → 우상단 **내 앱(My Apps)**
2. **BlueSeyo가 쓰던 앱** 선택. (없다면 **앱 만들기 → 유형 '비즈니스(Business)'** 로 새로 생성)
   - 새로 만들 때 이름 예: `oneulsalim-poster`
3. 왼쪽 메뉴 **앱 설정 → 기본 설정**에서 **앱 시크릿(App Secret)** 을 '표시' 눌러 확보
   → 뒤에서 장기토큰 교환에 필요. **메모장에만** 잠깐 저장.

> ⬛ 체크포인트 1 — 여기까지 화면 스샷 하나 주시면 다음을 정확히 짚어드립니다.

---

## B. 인스타그램 토큰 (graph.instagram.com)
1. 왼쪽 **제품 추가(+)** → **Instagram** → **설정(Set up)**
2. **"Instagram API 설정 (Instagram 로그인)"** 카드 선택
   (페이스북 페이지 없이 인스타 계정만으로 발행하는 방식 = 우리 poster가 쓰는 방식)
3. 권한(스코프)에 다음이 포함되는지 확인:
   - `instagram_business_basic` (= instagram_basic)
   - `instagram_business_content_publish` (= instagram_content_publish)
4. **"Instagram 계정 추가(Add account)"** → 팝업에서 **오늘살림 계정으로 로그인·허용**
5. 같은 화면의 **"액세스 토큰 생성(Generate token)"** 클릭 → 토큰 표시됨
   → 이게 **단기 토큰(약 1시간)**. 복사.
6. **장기 토큰(60일)으로 교환** — 브라우저 주소창에 아래를 붙여 실행:
   ```
   https://graph.instagram.com/access_token?grant_type=ig_exchange_token&client_secret=앱시크릿&access_token=단기토큰
   ```
   → 돌아온 JSON의 `access_token` = **`ig.accessToken`** (60일짜리) ✅
7. **IG 사용자 ID** 얻기 — 주소창에:
   ```
   https://graph.instagram.com/me?fields=user_id,username&access_token=장기토큰
   ```
   → `user_id`(숫자) = **`ig.igUserId`** ✅

> ⬛ 체크포인트 2 — 5번 '토큰 생성' 버튼이 안 보이거나 스코프 이름이 다르면 그 화면 스샷 주세요.

---

## C. 쓰레드 토큰 (graph.threads.net)
1. 같은 앱 → 왼쪽 **제품 추가(+)** → **Threads** → **설정**
2. **Threads 유스케이스** 추가, 스코프:
   - `threads_basic`
   - `threads_content_publish`
3. **오늘살림 쓰레드 계정 추가·로그인·허용**
4. **"액세스 토큰 생성"** → 단기 토큰 복사
5. **장기 토큰 교환** — 주소창에:
   ```
   https://graph.threads.net/access_token?grant_type=th_exchange_token&client_secret=앱시크릿&access_token=단기토큰
   ```
   → `access_token` = **`threads.accessToken`** ✅
6. **Threads 사용자 ID**:
   ```
   https://graph.threads.net/v1.0/me?fields=id,username&access_token=장기토큰
   ```
   → `id`(숫자) = **`threads.threadsUserId`** ✅

## D. config.json 채우기 (로컬 PC에서만)
```bash
cd autopost
copy config.example.json config.json   # Windows
```
`config.json`을 열어 4칸을 위에서 얻은 값으로 교체. `publicMediaBase`는 이미 채워져 있음(수정 불필요).

## E. 첫 발행 점검
```bash
node poster.cjs --dry --id 1전기세     # 실제 발행 없이 요청 확인
node poster.cjs --id 1전기세           # 진짜 발행 (IG+Threads)
```

## F. 60일 만료 방어
- 토큰은 ~60일. `node refresh-token.cjs`를 **주 1회** 스케줄에 걸면 자동 갱신.
- `run-daily.cmd`를 Windows 작업 스케줄러에 매일 등록하면 매일 1건 무인 발행.
