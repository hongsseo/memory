## 🔢 토큰 받은 뒤 — Threads 사용자 ID 얻기
브라우저 주소창에 (토큰 넣어서) 실행:
```
https://graph.threads.net/v1.0/me?fields=id,username&access_token=여기에_토큰
```
→ 결과의 `id`(숫자) = **threadsUserId** (이건 비밀 아님, 채팅에 알려줘도 됨)
