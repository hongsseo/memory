## ① 가계부 템플릿 (.xlsx) — 판매 9,900원
**구성:** 표지 · 설정(카테고리별 예산) · 대시보드(자동 계산) · 1~12월 입력 시트.
**작동 검증됨:** 월별 시트에 지출을 적으면 대시보드가 `SUMIF`로 카테고리별 지출을 집계하고, `VLOOKUP`으로 예산 대비 잔액·달성률을 자동 계산. 예산 초과 시 빨강 표시. 조회 월 드롭다운으로 12개월 전환.
> Excel · 구글 시트 · 넘버스 모두 호환. 카테고리·결제수단은 드롭다운.

**판매 채널:** 스마트스토어 or 크몽('디지털 콘텐츠'). 구매 시 파일 자동발송 설정.

### 판매 페이지 문안 (복붙용)
```
[한 달 -50만원, 오늘살림 가계부 템플릿]

가계부, 예쁘게 꾸미다 3일 만에 포기하셨나요?
오늘살림 가계부는 딱 하나만 합니다 — '숫자로 보여주기'.

✔ 카테고리별 예산만 정하면, 지출·잔액·달성률 자동 계산
✔ 예산 넘으면 빨간불로 바로 알려줘요
✔ 1~12월 한 파일 · 드롭다운으로 월 전환
✔ Excel·구글시트·넘버스 어디서나

복잡한 가계부는 그만. 오늘 쓴 돈만 한 줄씩 적으세요.
나머지 계산은 템플릿이 합니다.

* 구매 후 즉시 다운로드 · 개인 1가구용 · 재판매 금지
```

## ② 30일 체크리스트 (.pdf) — 무료 리드마그넷
**구성:** 표지(사용법+30칸 진행바) · 4주 × 하루 3미션(총 28일) · 마무리(가계부 업셀).
A4 인쇄용. 프린트해서 냉장고에 붙이거나 태블릿에 띄워 체크.

**배포 방식(택1):**
- 구글폼으로 이메일 받고 '제출 후 화면'에 PDF 다운로드 링크(구글드라이브 공유링크) 노출 → 이메일 리스트 확보
- 또는 인포크링크 파일첨부 기능으로 즉시 다운로드(간편, 리스트는 못 모음)
> 권고: **구글폼 방식** — 이메일을 모아야 나중에 가계부·냉파레시피를 재판매 가능.

---

## 파일 수정하려면
```bash
cd products
python3 build_budget_xlsx.py     # 가계부 재생성
python3 build_checklist_pdf.py   # 체크리스트 재생성
```
카테고리·예산 기본값은 `build_budget_xlsx.py`의 `CATEGORIES`/`default_budget`,
체크리스트 미션은 `build_checklist_pdf.py`의 `WEEKS`에서 수정.
