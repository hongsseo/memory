# 🟢 오늘살림 예약 앱으로 시작하기 (개발자 설정 없이)

토큰·코드 없이, **예약 앱에 오늘살림 쓰레드를 로그인**하면 끝입니다.
사장님 패드/폰이 꺼져 있어도 앱이 정해진 시각에 대신 올려줍니다.

---

## 1. 앱 고르기 (셋 중 하나, 무료로 시작)
| 앱 | 특징 | 대량 업로드(CSV) |
|---|---|---|
| **Buffer** (buffer.com) | 화면이 가장 단순. 초보 추천. | ❌ (하나씩 붙여넣기) |
| **Publer** (publer.com) | 28개 CSV 한 번에 올리기 가능 | ✅ |
| **Metricool** (metricool.com) | 한국에서 많이 씀 + 분석 | ✅ |

> **추천:** 하나씩 올려도 괜찮으면 **Buffer**(제일 쉬움). 28개를 한 방에 넣고 싶으면 **Publer**.
> ※ 무료 플랜 한도(월 예약 개수 등)는 가입 화면에서 확인하세요. 바뀔 수 있어요.

## 2. 가입 & 쓰레드 연결 (공통)
1. 위 앱 사이트 접속 → **Sign up**(구글/이메일로 가입).
2. **Connect / Add channel**(채널 연결) → 목록에서 **Threads** 선택.
3. 팝업에서 **오늘살림 계정으로 로그인 & 권한 허용** → 연결 완료.
   (이미 쓰레드 로그인돼 있으니 '허용'만 누르면 됩니다.)

## 3-A. 글 넣기 — Buffer(하나씩)
1. **Create Post** → 오늘살림(Threads) 선택.
2. `오늘살림_예약_붙여넣기.md`에서 글 하나 복사 → 붙여넣기.
3. **Schedule Post** → 해당 날짜·시간(예: 2026-07-13 07:30) 지정.
4. 28개 반복. (한 번 해두면 일주일 무인)

## 3-B. 글 넣기 — Publer/Metricool(한 번에)
1. **Bulk / Import**(대량 업로드) 메뉴.
2. `오늘살림_예약_28개.csv` 업로드.
3. 열 맞추기: **date=date, time=time, 내용=content** 로 매핑.
4. 미리보기 확인 → **Schedule all**. 28개가 한 번에 예약됩니다.

## 4. 끝!
이제 2026-07-13(월) 07:30부터 자동으로 올라갑니다.
2주차부터는 새 글만 같은 방식으로 예약하면 됩니다.

## 막히면
연결/업로드 화면 캡처를 보여주시면 어디를 눌러야 하는지 짚어드릴게요.
CSV 업로드 시 시간대(Timezone)는 **서울(GMT+9)** 로 설정하세요.
