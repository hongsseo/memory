# 💻 Developer: 롱폼 3편/주 자동 업로드 파이프라인 v0

**[CEO 지시]** 회사가 가장 필요로 하는 "매주 롱폼 3편 자동 업로드 파이프라인"을 설계한다. 1차 적용 채널: **WealthCD (일본 타깃 경제 유튜브)**.

## 0. 설계 원칙
- **반자동(human-in-the-loop)**: 완전 무인이 아니라, 사람은 "승인 버튼"만 누른다. 각 단계 산출물을 사람이 30초 안에 검수할 수 있게 만든다.
- **콘텐츠와 코드 분리**: 채널별 설정(톤·언어·타깃)은 `config`, 로직은 공통.
- **키 노출 금지**: 모든 API 키는 환경변수(`_agents/*/config.md` 또는 `.env`)로. git 동기화 제외.
- **재현성**: 각 단계 출력은 `sessions/<ts>/pipeline/`에 파일로 남겨 다음 단계가 파일을 읽어 이어간다(= 한 단계 실패해도 그 지점부터 재개).

## 1. 파이프라인 5단계 (아이디어 → 업로드)

```
[1] 아이디어 수집    →  ideas.json      (Researcher + trend_sniper)
[2] 스크립트 생성    →  script.md       (Writer, LLM)
[3] 음성/영상 합성   →  video.mp4       (TTS + B-roll 조립)
[4] 썸네일 생성      →  thumb_A/B/C.png (Designer 브리프 → 이미지)
[5] 메타데이터·업로드 →  upload.json     (YouTube Data API)
```

| 단계 | 담당 에이전트 | 입력 | 출력 | 도구/API | 수동 개입 |
|---|---|---|---|---|---|
| 1. 아이디어 | 🔍 Researcher | 채널 config, 최근 트렌드 | `ideas.json` (제목 후보 10 + 근거) | `trend_sniper`, YouTube Search API | 주 1회 5개 픽 |
| 2. 스크립트 | ✍️ Writer | 선택된 제목 1개 | `script.md` (후크+본문+CTA, 8~12분 분량) | LLM (Claude) | 후크 문장만 확인 |
| 3. 영상 합성 | 💻 Developer | `script.md` | `video.mp4` | TTS(일본어 음성) + B-roll/자막 조립 | 없음(자동) |
| 4. 썸네일 | 🎨 Designer | 제목, 핵심 키워드 | `thumb_A/B/C.png` 3안 | 이미지 생성 API | 1안 선택 |
| 5. 업로드 | 📺 YouTube | 영상+썸네일+메타 | 예약 게시 | YouTube Data API v3 `videos.insert` | 게시 승인 |

## 2. 단계별 상세

### [1] 아이디어 수집 — `ideas.json`
- 채널별 시드 키워드(WealthCD: 日本経済, 円安, NISA, 投資, 節約…)로 `trend_sniper` 실행 → 조회수/업로드일 대비 "떡상 지수" 상위 영상 패턴 추출.
- 출력 스키마:
  ```json
  { "channel": "WealthCD", "date": "2026-07-10",
    "ideas": [ { "title": "円安はいつ終わる?データで見る2026", "angle": "데이터 기반 예측",
                 "evidence": "유사 영상 3개 평균 12만뷰", "keywords": ["円安","2026","予測"] } ] }
  ```
- **자동화 포인트**: 사용자의 goal.md 핵심 고통("아이디어 수집에 시간 과다")을 여기서 해소. 주 1회 배치로 10개 후보 자동 생성 → 사람은 3개만 고름.

### [2] 스크립트 생성 — `script.md`
- 템플릿: `[0:00 후크 15초] → [문제 제기] → [데이터 3개] → [결론/전망] → [CTA 구독]`
- 채널 톤 주입: WealthCD는 일본어·정중체·데이터 인용 필수. 정치/투자 권유 단정 금지(회사 금기 준수).
- LLM 프롬프트에 `identity.md` + 채널 config를 시스템 컨텍스트로 주입.

### [3] 영상 합성 — `video.mp4`
- **최소 구성(v0)**: TTS 내레이션 + 자막 + 배경 B-roll/차트 이미지 슬라이드. (풀 편집은 Editor가 후속.)
- 파이프라인: `script.md` → 문장 단위 분할 → TTS(일본어) → 문장별 타임코드 → B-roll/차트 매칭 → ffmpeg 합성.
- **비용 주의**: TTS·이미지 API가 편당 과금. 편당 예상 비용을 `upload.json`에 기록해 ROI 추적.

### [4] 썸네일 — `thumb_A/B/C.png`
- Designer가 3안 자동 생성(색·타이포·후크 문구 변주) → 사람이 1안 선택 → A/B 테스트용으로 나머지 보관.
- WealthCD: 숫자+대비색+짧은 일본어 후크(예: "円安 いつまで?").

### [5] 메타데이터·업로드 — `upload.json`
- 제목/설명/태그/카드/예약시간 자동 생성. 일본 시청 피크 시간대(21:00 JST) 예약.
- YouTube Data API `videos.insert` (status.privacyStatus="private"→ 사람 승인 후 "public"/예약).
- **안전장치**: 최종 게시는 항상 사람 승인 1클릭. 무단 자동 공개 금지.

## 3. 3편/주 운영 캘린더 (WealthCD 기준 예시)
| 요일 | 산출물 | 단계 실행 |
|---|---|---|
| 월 | 주간 아이디어 배치 | [1] 자동 → 사람 3개 픽 |
| 화·목·토 | 롱폼 1편씩 | [2]~[5] 편당 실행, 게시 승인 |
| 일 | 성과 리뷰 | 조회수/CTR → `ideas.json` 피드백 루프 |

## 5. 리스크 & 가드레일
- **YouTube API 쿼터**: `videos.insert`는 쿼터 소모 큼(1600 units). 하루 3편이면 여유. 아이디어 수집 Search 호출이 쿼터 대부분 소모 → 캐시(`_cache/`) 필수.
- **품질 하한선**: 완전 자동 영상은 조회수 저조 위험. v0는 "초안 자동 생성 + 사람 폴리싱" 하이브리드로 시작.
- **금기 준수**: 경제 콘텐츠라도 특정 종목 매수 권유·정치 프레임 자동 삽입 방지 필터 필요.
