# 🎬 오늘살림 숏츠 (유튜브 쇼츠)

살림 카드(1080x1350) 4장을 **세로 숏츠(1080x1920)** 무음 모션카드로 자동 변환합니다.
새로 찍지 않고 기존 카드 재활용 → 글만 바꾸면 무한 생산.

## 파일
- `build_shorts.sh` — 생성기. `products/cards/`의 card{n}-1~4.png → `오늘살림_{id}_숏츠.mp4`.
- `유튜브_업로드_메타.md` — 숏츠별 제목·설명(쿠팡/프로필 링크·고지문)·해시태그.
- `out/` — 생성된 mp4 (git 제외).

## 사용
```bash
bash build_shorts.sh            # ./out 에 5개 생성
bash build_shorts.sh /원하는/폴더
```

## 스펙
- 1080x1920, 30fps, 무음, 카드당 4초 + 0.5초 크로스페이드 → 총 14.5초.
- 배경 여백은 크림(#F4EEE1)으로 카드와 자연스럽게 연결.
- 음악은 유튜브 쇼츠 편집에서 트렌드 사운드 추가(무음 업로드 후).

## 수익 경로
- 유튜브 쇼츠는 **설명란 링크 클릭 가능** → 상품 숏츠는 설명 맨 위 고지문 + 쿠팡 링크.
- 일반 숏츠는 프로필 '살림템 모음'(인포크) 유도.
